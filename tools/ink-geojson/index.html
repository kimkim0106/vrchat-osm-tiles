ペンの線の取り出し

VRChat のログから、設定タブレットの「書き出す」で出した GeoJSON (地図用のペンで書いた線) を取り出します。ログはこのページの中だけで読み、どこにも送りません。

ログのファイルをここにドロップ

VRChat の output_log_*.txt か、Unity エディタの Editor.log。複数まとめて選べます。

ログの場所
  • VRChat (PC): %USERPROFILE%\AppData\LocalLow\VRChat\VRChat (エクスプローラーのアドレス欄に貼ると開けます)
  • Unity エディタ (Windows): %LOCALAPPDATA%\Unity\Editor\Editor.log
  • Unity エディタ (macOS): ~/Library/Logs/Unity/Editor.log (Finder で ⇧⌘G に貼ると開けます)
  • Quest / Android ではログを取り出しにくいので、タブレットの欄からコピーしてください。

ログの一部を貼り付けて取り出す

書き出したファイルは RFC 7946 の GeoJSON (WGS84 の [経度, 緯度]) なので、QGIS や geojson.io でそのまま開けます。タブレットの GeoJSON タブに貼ると床の地図にも重ねられます (5 万字まで)。
